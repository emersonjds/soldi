# SOL-188 — Planilha: a month total row

Owner report (2026-11-27): a 700,00 Entrada on 27 Nov "did not add up" in the 4.575,19 on the last row. The last row is day 30 itself; the planilha has no total row, so the last day reads as one.

## Brief

Each month table gets a `<tfoot>` row after its last day:

| Column  | Value                                                                 |
| ------- | --------------------------------------------------------------------- |
| Data    | "Total" (`<th scope="row">`, accessible name "Total de <mês>")        |
| Entrada | sum of every row's `income` (income + resgates)                        |
| Saída   | sum of every row's `outflow` (paid + unpaid landed contas; skipped never count) |
| Diário  | sum of what each row's Diário cell shows (`daily` when the previsto is on and the day has one, else `day.daily`) |
| Saldo   | the last day's `projected_balance`, painted with its `projected_tier` like a day cell, plus the sr-only tier label |

- The totals are the exact sum of the cells above them: computed in the web from `planilhaRows` with `sum`, never a float. Days before the opening date add zero.
- Look: semibold text, a 2px top rule (`border-t-2`), the card background (no weekend tint), not italic, zero shown as the same muted "-" as a day cell. Not clickable, no hover, not part of the roving tab stops.
- The Data cell stays sticky like the day cells.
- A month still loading or failed shows no total row (the skeleton keeps its size; the error row stays as is).
- A month with no days on or after the opening date shows no total row.
- No contract change, no new token or component.

## Acceptance

1. A month's total row sums Entrada, Saída and Diário exactly as the cells show them, including a future-dated Entrada and the Diário previsto when on.
2. Saldo in the total row equals the last day's projected balance and carries its tier color and label.
3. Screen readers hear "Total de <mês>" and each column header for each value.
4. Keyboard: arrow navigation never lands on the total row; clicking it opens nothing.
5. `expectNoClipped` passes at 375, 1024, 1280 and 1440 with the total row visible.
