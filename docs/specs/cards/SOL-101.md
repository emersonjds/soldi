# SOL-101 — Change a category's kind and carry its entries along

Owner request (2026-11-12): categories created as Diário that are really Saídas (Aluguel, Fies, Porto) can only be fixed today by recreating them and editing every entry.

## Rules

- `PATCH /api/categories/{id}` accepts `kind`, `daily` or `bill` only.
- The change applies to a top-level category, and its subcategories follow. A subcategory alone keeps its parent's kind, so the API refuses it with 422 `kind-of-subcategory`.
- Economia, its cofrinhos, Resgate and income categories never change kind. The API refuses them with 422 `kind-locked`.
- Every entry of the category and its subcategories takes the new kind, series members included, all in one transaction.
- The new kind must not already hold an active category with the same name as the category or any of its subcategories. A clash gives 409 `duplicate-name`, naming the clash.
- A category used by an active conta fixa cannot become Diário. The API refuses it with 422 `category-has-bills`.
- The category takes the lowest free color of the new kind, and its subcategories wear it.
- The running balance does not change: Diário and Saída are both outflow.

## Web

- In Ajustes › Categorias › Editar, a category at the top level shows `Tipo` with `Diário` and `Saída`.
- Changing it asks for confirmation: `Mudar para {Saída|Diário}?` with `Todos os lançamentos de {nome} e das subcategorias passam a ser {Saída|Diário}. O saldo não muda.` and `Mudar tipo` / `Cancelar`.
- Errors use the problem's detail, in pt-BR.
