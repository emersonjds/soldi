# SOL-163 — Modo planilha

Owner, 2026-11-23: "A second way to see Mês, chosen by the person at any time; the current view stays. One row per day (all days), columns Entrada / Saída / Diário / Saldo, saldo cell colored by tier, months side by side with horizontal scroll (today's month + 11 months, 'ir pra hoje'). Hover (desktop) or tap (mobile) on a day shows that day's entries and contas, as the sheet does."

Reference: `_Termômetro.xlsx`, tab "2026": per month a 5-column block (merged title `JANEIRO`…, headers `Data | Entrada | Saída | Diário | Saldo`, one row per day, Data = day number) plus a spacer column, 12 blocks side by side; Saldo runs across months and can go negative; 230 cell comments list the items behind a value ("Casas Bahia p3 - 59.17").

Web only. No contract change: each month block reads `GET /api/months/{month}` (`MonthView.days`, `bills_of_month`) and `useTransactions(month)`, the same queries and cache keys Mês already uses. New component (the planilha), no new token. `pixel` runs (new component): 375 and 1440, light.

## What stays exactly as today

- **Lista is the default** and is pixel-for-pixel today's Mês: hero, Contas a pagar, Termômetro, Lançamentos with its filters (Todos · Diário · Contas fixas · Valor variável), Próximos meses, Cofrinhos, Para onde vai, RedDayAlert, the `useStoredOpen("ledger")` collapse.
- Hero (Saldo hoje, Projetado, Lançar, month switcher) stays first and biggest in both views. Lançar is the one primary action in both.
- Every tap count of today's flows (Lançar, Pagar, edit an entry, switch month) is unchanged. Planilha adds one opt-in tap, once.
- When Lista is chosen and the month has no entries, Lançamentos hides as today (smart containers).

## Changes

1. **Switch.** The Lançamentos header gets a two-option segmented control **"Lista" / "Planilha"** (`ToggleGroup`, same style as the filter chips, `min-h-11`, text-base), between the title and the collapse chevron; at 375 it wraps to its own full-width line under the title (`grid-cols-2`) when it does not fit. Choosing a view also opens a collapsed section. The choice is stored in the browser the same way as `useStoredOpen` (key `ledger-planilha`, default off; the hook can be reused as-is: open = Planilha). No URL parameter.
2. **Planilha mode** replaces only the Lançamentos body (filters and day groups) with the planilha. Everything else on the page stays. At `xl` the page drops its two-column grid and uses the `lg` single-column flow (hero, Contas a pagar, Lançamentos, then the 2-column card grid), so the planilha gets the full content width. Mobile order unchanged (Lançamentos keeps `order-3`).
3. **Grid.** One horizontal scroller (`overflow: auto`, `max-height: 80dvh`, `overscroll-behavior-x: contain`) holding one `<table>` per month, side by side, with a gap as the sheet's spacer column. Per table:
   - header row 1: month title `monthLabel` ("Novembro 2026"), `colSpan=5`; header row 2: **Data | Entrada | Saída | Diário | Saldo**. Both rows `position: sticky; top: 0` inside the scroller.
   - one row per calendar day; Data = day number, `sticky; left: 0` within its table (matters only when a month is wider than the scroller).
   - cells: Entrada = `income + withdrawn`; Saída = `bills` + the `amount` of every `bills_of_month` row with `lands_on` = that day (unpaid contas landed, D16/D17); Diário = `daily`; Saldo = `projected_balance` with `projected_tier` (the same pair the Ledger day header shows). With these, Saldo(d) = Saldo(d−1) + Entrada − Saída − Diário inside a month.
   - money without the `R$` symbol (the caption says "Valores em R$"), exact cents from the API string through the existing pt-BR formatter, `tabular-nums`, right-aligned, font `clamp(0.75rem, 3.6cqi, 0.875rem)`. A zero cell is blank (as the sheet). Values never truncate: a column grows to its widest value.
4. **Width.** A month table is at least `100cqi / n` of the scroller (container query): n = 1 below 40rem, 2 from 40rem, 3 from 64rem, and wider when its values need it. Scroll-snap: `x mandatory`, each table snaps at its start. Expected: 375 → 1 month, 1024 → 2, 1280 → 2, 1440 → 3.
5. **Horizon.** Months from `max(opening month, today's month − 12)` to today's month + 11 (D16's 12-month horizon ahead; the past back to the owner's sheet year). A block fetches its month when it comes within one block of the scroller's view (IntersectionObserver, root = scroller) and keeps a skeleton of the same size until then (no layout shift). The planilha opens with the URL month `m` (default today's month) at the scroller's start; `m` outside the range opens at the nearest end. When `m` is today's month, today's row is scrolled to the vertical center. Changing `m` (hero switcher, a Próximos meses chip) scrolls the planilha to that month; scrolling the planilha does not change `m`.
6. **"Ir pra hoje"** (ghost button with `CalendarCheck` icon, `min-h-11`) sits in the planilha toolbar, right-aligned. Visible when today's row is not fully inside the scroller's view or `m` is not today's month; otherwise `invisible` (space kept, `aria-hidden`). It sets `m` to today's month (`replaceUrl`, so the hero follows), scrolls today's month to the start and today's row to the center (smooth unless `prefers-reduced-motion`), and focuses today's row.
7. **Row marks.**
   - Today: day number in a filled `primary` circle, row `aria-current="date"`, accessible name ends in "hoje".
   - Saturday and Sunday: `bg-muted/50` row; the weekday is in the row's accessible name.
   - Previsto (not happened yet): money in italics. Future rows: Entrada/Saída/Diário in italics and `muted-foreground`; Saldo in italics. Today's and past rows: Saída in italics when it holds an unpaid conta landed that day; Saldo in italics when `projected_balance ≠ balance` (the Ledger's `isForecast`).
   - Saldo cell: `TIER_STYLE[projected_tier].pill` (soft background + tier text, AA ≥ 4.5:1 per tokens.md), always filled even when the value is 0. Crítico and Atenção add a `TriangleAlert` glyph (aria-hidden) before the value; every Saldo cell carries the tier word in `sr-only` ("Crítico", "Atenção", "Apertado", "Confortável", "Folga").
   - Days before the opening date (opening month only): every cell blank, Saldo included; row text `muted-foreground`.
8. **Legend** under the scroller, wrapping: "Itálico: previsto" · five `TierPill size="sm"` (no amount): Crítico, Atenção, Apertado, Confortável, Folga.
9. **Day detail.** The day button in the Data cell is the row's control; a tap/click anywhere on the row triggers it.
   - Fine pointer (`(hover: hover) and (pointer: fine)`): `Popover` anchored to the row, opens after 300 ms hover on a day that has entries or contas (like a cell comment), and on click or Enter/Space on any day; closes 150 ms after the pointer leaves both row and popover, or on Esc (focus back to the row).
   - Otherwise: bottom `Sheet` with a close button, swipe/Esc to dismiss, focus back to the row.
   - Content, read-only, reusing the Ledger's words: title `dayLabel` ("Hoje, 5 nov", "Ontem, 4 nov", "Previsto · 28 nov", "12 nov"); the Ledger header's balance line ("Saldo ao final:" / "Projeção:" + Money + `TierPill`); then up to three groups, each only when non-empty, headed by the column name and its total (equal to the cell): **Entrada**, **Saída**, **Diário**. Items: title (`note` or category label), caption (the Ledger's `entryOf`/`dueCaption`: "Entrada", "Resgatado", "Guardado", "Conta fixa · paga", "Parcela 2/6 · a pagar", "Fatura · a pagar", "Conta fixa · venceu dia 3/11 · valor variável", "Diário"), Money amount. Unpaid contas sit in Saída after the entries.
   - Future days show only what was entered and the contas landed on them; no daily spending is estimated (D16). SOL-164 may later add a "Diário previsto" line to the Diário group and an italic value to the cell; nothing is reserved for it now.
   - No edit from the detail: editing stays in Lista.
10. **Keyboard.** One tab stop per month table (roving tabindex on day buttons): ↑/↓ previous/next day, Home/End first/last day, ←/→ the same day in the previous/next month (clamped to its last day; scrolls it into view), Enter/Space opens the detail. Tab leaves the table.
11. **RedDayAlert "jump"** in Planilha mode scrolls the planilha to that day's row (both axes), focuses it and rings it with `ring-expense` for 2 s, as the Ledger does today. Same tap count.

## Research (switch to a day grid, find a day's detail, back to today)

- **Owner's sheet (Excel) / Google Sheets:** the whole year is the grid; frozen header rows; a cell note shows on hover (desktop) and on tap in the mobile app; no "today" control (scroll or Ctrl+F).
- **Organizze:** "Fluxo de caixa com entradas, saídas e saldo de cada dia, mês a mês" (App Store listing); a report reached from the Relatórios menu, one month at a time with month arrows (menu path from memory, not re-verified).
- **CalendarBudget / CalBudget:** a calendar where every paycheck and bill sits on its day and "carries the running balance into every following day", flagging "low" days ahead (calbudget.com); detail by day on the calendar; interaction not documented on the site.
- **YNAB:** no per-day balance or day grid (the register lists transactions); not a model here.
- **Mobills:** dashboard + monthly lists; no day-by-day balance grid found.
- Takeaway: the sheet idiom (frozen headers, hover note) and the calendar idiom (running balance, low days flagged ahead) both put the balance per day in one glance; none of them needs more than one tap to see a day's items.

## D48 draft — Mês has an opt-in Modo planilha (2026-11-23, owner + SOL-163)

Lançamentos can render as a day grid (Data, Entrada, Saída, Diário, Saldo) of months side by side, today's month − 12 (not before opening) to + 11, chosen in its header and remembered in the browser; Lista stays the default and unchanged. Saída includes unpaid contas on their landing day and Saldo is `projected_balance`/`projected_tier`, so a month's rows add up and red shows ahead (D16, D17). Read-only detail per day. Trade-off: nested scroll region and one more view to maintain; no API change.

## States

| State | What shows |
|---|---|
| Loading (settings) | the toolbar and one skeleton month block; `role="status"` "Carregando". |
| Loading (a month) | that block's title and headers, 31 skeleton rows of the final size. |
| Error (settings) | `PageError` "Não foi possível carregar a planilha." + "Tentar de novo" in place of the scroller. |
| Error (a month) | inside that block, under its headers: "Não foi possível carregar {Março 2027}." + "Tentar de novo" (`min-h-11`); other blocks unaffected. |
| Error (entries only) | cells show (they come from the month view); the detail lists that day's contas and the line "Não foi possível carregar os lançamentos deste dia." + "Tentar de novo". |
| 422 `month-before-opening` (opening date moved in another tab) | block text "Este mês é anterior ao seu saldo inicial."; no retry; the range recomputes when settings refetch. |
| Empty month (no entries) | all days with Saldo carried, other cells blank; no extra message (Lançar is in the hero). |
| Empty day | detail: "Nada lançado neste dia." (today or past) / "Nada previsto para este dia." (future). |
| Before the opening date | blank row; detail: "Este dia é anterior ao seu saldo inicial." |
| Offline | the per-month error above for months not cached; cached months still show. |
| Overflow | 6+ digit values widen their column and the month; long item names wrap in the detail. |
| Collapsed | header (title, switch, chevron) only, as today. |

## Acceptance

Unit tests: today = 2026-11-05, opening date 2026-03-10, `m` = 2026-11. e2e: the existing seed.

- A1 Default: with nothing stored, Mês renders exactly today's Lista (existing `mes/page.test.tsx` and Ledger tests pass unchanged); the switch shows "Lista" pressed.
- A2 Switch: tapping "Planilha" shows the planilha in the Lançamentos slot and hides the filters; reloading keeps Planilha; "Lista" brings back today's Ledger with filter "Todos". Choosing a view while collapsed opens the section. The URL does not change.
- A3 Range: blocks run Março 2026 … Outubro 2027 (20 tables, captions in order); with opening 2025-01-01 they run Novembro 2025 … Outubro 2027. No request goes out for a month before the opening month.
- A4 Lazy: on open only the visible block(s) and their neighbours request `/api/months/{m}` and transactions; scrolling to a block requests it once.
- A5 Rows: Novembro 2026 has 30 rows, Fevereiro 2027 28; each row's cells match the API: Entrada = income + withdrawn, Saída = bills + `lands_on` amounts, Diário = daily, Saldo = projected_balance; zero cells blank; for every day d > 1 of a month, Saldo(d) = Saldo(d−1) + Entrada − Saída − Diário.
- A6 Saldo cell: class from `TIER_STYLE[projected_tier].pill`; red and light_red cells show the glyph; every cell's text includes the sr tier word; negative values render with "-" in pt-BR format ("-1.150,00").
- A7 Marks: today's row has `aria-current="date"` and its day in the primary circle; Saturday/Sunday rows have the muted background; future rows and landed-unpaid Saída are italic; days 1–9 of Março 2026 are blank.
- A8 Detail (fine pointer): hover 300 ms on a day with items opens the popover; hover on an empty day opens nothing; click on an empty past day shows "Nada lançado neste dia.", on an empty future day "Nada previsto para este dia."; Esc closes and returns focus to the row. Groups show only when non-empty and their totals equal the cells; an unpaid parcela reads "Parcela 2/6 · a pagar".
- A9 Detail (touch, 375): tapping a row opens a bottom sheet with the same content and a close button; no popover.
- A10 Keyboard: Tab reaches one day per month; ↑/↓/Home/End move inside the month; → from 31 jan reaches 28 fev; Enter opens the detail.
- A11 Ir pra hoje: hidden (`invisible`, `aria-hidden`) on open with `m` = today; visible after scrolling today out of view or with `m` = 2027-02; tapping it sets `m` to 2026-11, scrolls today's row into view and focuses it.
- A12 `m` sync: changing month in the hero switcher or a Próximos meses chip scrolls the planilha to that month; scrolling the planilha leaves `m` unchanged.
- A13 Errors: month request fails → only that block shows "Não foi possível carregar {month}." and "Tentar de novo" refetches it; settings fail → "Não foi possível carregar a planilha."; transactions fail → cells still render and the detail shows "Não foi possível carregar os lançamentos deste dia."; a 422 `month-before-opening` block shows "Este mês é anterior ao seu saldo inicial."
- A14 RedDayAlert jump in Planilha mode scrolls to and focuses that day's row with the 2 s ring.
- A15 xl: in Planilha mode at 1280 and 1440 the page uses the single-column flow; in Lista it keeps the two-column grid.
- A16 e2e `web/e2e/planilha.spec.ts` at 375, 1024, 1280, 1440: `expectNoClipped` passes; `document.scrollingElement.scrollWidth ≤ innerWidth` (horizontal scroll only inside the planilha); fully visible month titles: 1 at 375, 3 at 1440; at 375 the switch, day buttons and "Ir pra hoje" are ≥ 44 px tall; switch → Planilha → reload keeps it; tap a seeded day → its entries listed; "Ir pra hoje" returns to today.
- A17 Light only. `pixel`: Mês in Planilha mode, 375 and 1440, one script, existing seed.
