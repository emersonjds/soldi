# SOL-171 — Planilha editável

Owner, 2026-11-24: "In modo planilha: (1) lines like a real Excel sheet on every cell, in a light color; (2) hover keeps showing the day detail, but clicking must work like a lançamento: add, remove or edit values from the sheet, as in Lista. An empty money cell shows '-' (no value). Keep the Parcelado and conta fixa (Mensal) mechanics, so the sheet is a visual future projection like my `Termômetro.xlsx`; (3) the side column (Termômetro do Mês, Próximos meses, Cofrinhos, Para onde vai) is not needed in planilha mode: hide it."

Builds on D48 (`SOL-163.md`), D49 (`SOL-164.md`), SOL-170 (full width, whole months, up to five). Web only. **No API change**: every action reuses an existing mutation (`useCreateTransaction`, `useUpdateTransaction`, `useDeleteTransaction`, bill edit through `EditBillSheet`). No new token, no new component file beyond one extraction (`entry-actions.tsx`), so no `pixel` run (`visual-verification.md`); widths by `expectNoClipped`.

UX panel of one (ux brief; product and finance angles voted inline). Read: D28, D47, D48, D49, SOL-163 §9–§10 and States, SOL-164 S8/S9; code `planilha.tsx` (`DayDetail`, `Row`, `MonthBlock`, `SkeletonBody`, `Toolbar`), `ledger.tsx` (`Ledger` action sheet, `Row`, `DueRow`), `transaction-sheet.tsx` (`TransactionSheetProps`), `bills-of-month.tsx` (`openName`), `mes/page.tsx`, `transaction-queries.ts` (optimistic list, month refetch on settle), `soldi.css` (`--border: #e6e6ff`).

User goal: "Quero mexer nos valores direto na planilha, como no meu Excel: clicar num dia futuro e lançar, clicar num valor e corrigir ou apagar, sem trocar para a Lista."

## What stays exactly as today

- **Lista** is untouched: rows, action sheet (Editar / Excluir, series scope, Desfazer), filters, tap counts. The action sheet is moved to its own file and reused; Lista's tests pass unchanged (proof of no regression).
- Planilha columns, values, italics, tier pills and glyphs, weekend tint, sticky headers and Data cell, today circle, RedDayAlert ring, legend, `EstimateNote`, "Ir pra hoje", horizon, lazy loading, roving tabindex and arrow keys (↑/↓ day, ←/→ month, Home/End).
- **Hover peek**: fine pointer, 300 ms on a day with items opens the read-only-looking detail popover; 150 ms leave closes it.
- **Data cell and Saldo cell** click / Enter / Space open the day detail as today (popover on fine pointer, bottom sheet on touch).
- Hero (Saldo hoje, Projetado, Lançar as the one primary action, month switcher), Contas a pagar and RedDayAlert stay on the page in planilha mode.
- Lançar sheet, its kinds and D47's Conta + Parcelado + Mensal: the same `TransactionSheet`, only prefilled.

## Market check (the exact steps: add on a day, edit one value, delete one occurrence)

| App / screen | Add on a given day | Edit one value | Delete one occurrence of a series | Cell = sum of items? |
|---|---|---|---|---|
| Owner's `Termômetro.xlsx` / Google Sheets grid | click the cell, type, Enter (1 click) | click, type over (1) | click, Delete (1); no series concept | yes: the cell comment lists the items; typing over a sum loses them |
| PocketSmith Calendar ([creating a budget](https://learn.pocketsmith.com/article/206-creating-a-new-budget), [editing/deleting](https://learn.pocketsmith.com/article/174-editing-moving-or-deleting-a-budget), [repeating budgets](https://learn.pocketsmith.com/article/245-repeating-budgets-and-how-to-delete-or-make-changes-to-them)) | click the day → budget form → Save (2 + typing) | click the event → form → Update (2) | click event → Delete budget → "This occurrence only" (3) | no: each event is its own chip on the day |
| CalBudget calendar ([add, edit and move](https://www.calbudget.com/help/add-edit-and-move-transactions), [recurring](https://www.calbudget.com/help/create-recurring-bills-and-income)) | select the day → quick-entry row (title + amount) → Enter (1–2 + typing); recurring needs the full form | click the item → form → save (2) | item → choose "this occurrence" vs series → delete (3) | no: items listed inside the day |
| Soldi Lista (today) | hero Lançar → date field → day in calendar (+ month arrows) → category → Salvar (≈5) | row → Editar → sheet (2) | row → Excluir → Só esta → Excluir (3) | n/a |

Takeaways: spreadsheets make the cell the target, calendars make the **day** the add target and the **item** the edit target, and every app that has series asks "this one or all" on edit/delete. Soldi's cell is a sum (several entries, an unpaid conta, a Diário previsto), so it takes the calendar rule inside the sheet idiom: an empty cell adds, a cell that is exactly one lançamento opens it, anything else opens the day's items.

## Accessibility

- Color never alone: tiers keep glyph + sr word; previsto keeps italic + label; "-" has sr "sem valor"; gridlines are decorative.
- Every action is keyboard-reachable: Tab to a month's Data button → Enter/Space → detail → Tab through item buttons and "Lançar neste dia" buttons; Esc / sheet close returns focus to the Data button.
- Item buttons: `min-h-11`, `hover:bg-muted`, `focus-visible:outline-2` (Lista `Row` classes); add buttons `min-h-11`.
- Money cells: `cursor-pointer`, `hover:bg-muted/60` on fine pointer only (the tier pill keeps its own color on Saldo, which is not hovered).

## D-entry (draft for `docs/specs/decisions.md`; amends D48)

**D50 — The planilha is editable by cell (2026-11-24, owner + SOL-171; amends D48)**
D48's read-only day detail becomes actionable. In Modo planilha a click on Entrada, Saída or Diário acts on that day and column: an empty cell (or only a Diário previsto) opens Lançar with the column's kind and the row's date; a cell that is exactly one lançamento opens Lista's Editar / Excluir sheet (series scope and Desfazer unchanged); anything else opens the day detail, whose items open the same sheet (unpaid contas open Editar conta, faturas and the previsto stay text) and which offers "Lançar neste dia" Entrada / Saída / Diário. Data and Saldo still open the detail; hover still peeks. Empty money cells show "-"; gridlines use `--border`. No inline typing: a cell is a sum. Planilha mode hides the right column (Termômetro, Próximos meses, Cofrinhos, Para onde vai). Trade-off: one cell, three outcomes by content; keyboard adds through the detail. No API change. Detail: `docs/specs/cards/SOL-171.md`.
