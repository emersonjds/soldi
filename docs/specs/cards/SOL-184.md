# SOL-184 — Pick the app palette in Ajustes

Owner, 2026-11-25: 0.72.0 (D51) lost identity because the hero turned white. Six brand palettes, prototyped in https://claude.ai/artifact/K6TDDTn7PPcCNGVPKEVWfK, ship in the app so the owner chooses in real use. Recorded as D52.

## Decisions

- **Per device, not per account.** The choice lives in `localStorage` (`soldi-palette`), like `shared/lib/use-stored-open.ts`. No migration and no API change. Server sync is a follow-up only if someone asks to have it across devices.
- **Default stays "Mel e menta"** (0.72.0, white hero) until the owner picks; the pick then becomes the default in a follow-up card.
- **Only brand tokens change.** Termômetro tiers, income/expense, categories, neutrals and the page background (white) are the same in every palette. Folga stays green, Crítico stays red.
- **The hero is colored again**, flat (no gradient), from a `--hero` token. In the default palette `--hero` is the card white with dark text, so 0.72.0 looks the same.
- No flash on load: an inline script in `<head>` sets `data-palette` on `<html>` before paint, reading the stored value against the allowed list (try/catch; anything else = default). The server already hashes inline scripts from `web/out` for the CSP.

## Picker (Ajustes)

- New `SettingsSection` `id="cores"`, icon `Palette` (lucide), title "Cores do app", subtitle "Escolha a paleta do Soldi. Vale só neste aparelho.", placed first in the page and in `widgets/settings/settings-nav.tsx` (label "Cores do app").
- A `radiogroup` (`aria-label="Paleta"`) of 7 options in a grid (1 column at 375, 2 from `sm`, 3 from `xl`). Each option is a button `role="radio"` with `aria-checked`, min height 44 px: three swatches (hero, brand, soft) and the name. Selected: `ring-2 ring-ring` and a check icon. Arrow keys move between options (native radio inputs styled as cards are fine and preferred).
- Choosing applies at once: set `document.documentElement.dataset.palette` (removed for the default) and store the value. No toast, no save button.
- Lives in `features/pick-palette/` (`palette-picker.tsx` + `palettes.ts` with the list of `{ value, name, hero, brand, soft }` — the single source the boot script's allowed list also uses).

## Acceptance

- Unit (`web/src/app/palette.test.ts`): for each of the 7 palettes, ≥ 4.5:1 for white on brand, white on brand ink, brand ink on soft, hero-foreground on hero (opaque heroes), wordmark on white; each block in `palettes.css` sets every token listed above.
- Unit: picker renders 7 radios, the default checked with nothing stored, choosing one sets `data-palette` and the stored value, the default removes both; a stored unknown value falls back to the default. Boot script: allowed values only.
- e2e (new `e2e/palette.spec.ts`): pick "Ameixa e mel" in Ajustes, reload, `<html data-palette="ameixa">` and the Mês hero background is `rgb(58, 39, 88)`; `expectNoClipped` on Ajustes at 375, 1024, 1280, 1440. CSP spec stays green.
- Full gate green; coverage > 90 % on the 4 metrics.
