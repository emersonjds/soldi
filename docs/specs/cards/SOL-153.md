# SOL-153 — Contas a pagar: every bill of the month on Mês, in groups

Owner, 2026-11-22. Contas a pagar on Mês shows the month's bills as expandable groups with the paid count in the title, and each row reaches edit and removal. Today edit and removal live only behind Ver todas > ⋯ > Arquivar, which the owner could not find.

Builds on SOL-152 (`BillOfMonth.variable`, `is_card`; D44). Web only: no contract, no migration.

## 1. What stays exactly as today

- The row (`Row` in `widgets/bills-of-month/bills-of-month.tsx`): icon, name, parcela text, `≈` + "valor variável" while unpaid, Caption, the amount button that opens Pagar, `BillStatus` (Pagar / Vencido / ✓ Pago), and the round check at ≥ 1024. Pay, the round check, undo and their toasts are untouched.
- A card's name opens FaturaSheet (SOL-119).
- Server order: by due date, so bills carried from earlier months (D17) come first.
- Zero bills: the widget renders nothing (containers rule; Contas fixas keeps its own empty state).
- Day chips at ≥ 1024, same filter, same second-tap clear.

## 2. Research (from `docs/research/2026-11-14-*`)

- Grouped lists with a header per group: YNAB (group header carries the actions), Monarch and Copilot (category groups), Mobills (list grouped by parent). Benchmark §categories: expand/collapse is rare on mobile because counts are small, so lists stay open by default.
- Edit and delete from the row: the common pattern is "tap row → edit; delete inside edit" (Mobills tap → edit, Revolut "…" → Edit category, YNAB inline). Nobody sends the user to a settings page to fix one bill.
- Audit (Mês): one number, then what is coming, then detail; a collapsed header is fine for what the user does not act on now ("Próximos" in Lançamentos).

Trade-off: all-open makes the card long with 10+ bills at 375; in exchange no action costs more taps than today and nothing is hidden.

## 4. Layout

### 375 (mobile first)

- Title line: "Contas a pagar" + pill "5 de 10 pagas" (pill wraps under the title if it must; `flex-wrap`, no fixed width). Replaces mobile "Contas do Mês" and "N obrigações cadastradas" (deliberate Stitch deviation, asked by the card).
- Subtitle (text-sm, muted), one line that wraps by fragment (`whitespace-nowrap` per fragment):
  - overdue fragment first when any: Clock icon + "2 vencidas" in `text-expense`;
  - then `Próxima: dia 25 · R$ 180,00` (`≈ ` before the amount when that bill is variable), or `ALL_BILLS_PAID` ("Todas as contas do mês pagas") when every row is paid.
- Groups, in order, each a `Collapsible` (`web/src/components/ui/collapsible.tsx`, first consumer; no Accordion, groups are independent):
  - header = `<h3>` wrapping a full-width `CollapsibleTrigger` button, `min-h-11`: line 1 group name (font-medium) + ChevronDown (rotates 180° when open, `motion-safe` 150 ms); line 2 the summary (§5). Radix sets `aria-expanded`.
  - content = the same `<ul>` of `Row`s.
  - a group with no rows is not rendered.
- Row: as today, plus the name area of a non-card row becomes a button (same classes as the card's: `min-h-11`, ChevronRight) labelled `Editar {label}`. It opens `EditBillSheet` with the bill found by `bill_id` in `useBills()`.
- Footer: link "Gerenciar contas fixas" → `/ajustes/contas`, `min-h-11`, `text-primary text-sm`, left-aligned.

### 1024

- Same as 375, plus: the round check shows (as today); the day-chip `ToggleGroup` sits between the subtitle and the first group, alone in its row (Próxima moved to the subtitle).
- Row Caption desktop text as today.

### 1440

- Same as 1024 inside the Mês `2fr` column. No new breakpoint rule.

## 5. States and exact copy

| State | What shows |
| --- | --- |
| No bills | Nothing (widget returns null). |
| Some paid | Title pill "5 de 10 pagas"; group summary "2 de 3 pagas · falta R$ 1.234,56". |
| One bill in a group | "0 de 1 paga · falta R$ 180,00"; "1 de 1 paga" when paid. Title too: "0 de 1 paga". |
| Group all paid | Summary: Check icon + "3 de 3 pagas" in `text-income-text`; no "falta". Stays open. |
| All paid | Pill "10 de 10 pagas"; subtitle "Todas as contas do mês pagas". |
| Overdue (this or an earlier month) | Row as today (`bg-expense/10`, Vencido, "Atrasada desde …", "venceu em outubro" on a carried parcela). Group summary appends "· 1 vencida" / "· 2 vencidas" with Clock icon, `text-expense`. Subtitle starts with the same fragment. Never color alone. |
| Variable not adjusted | Row as today (`≈`, "valor variável"). Variable group summary "falta ≈ R$ 430,00". |
| Card fatura unpaid / paid | Row as today: Pagar and the check open Pagar (D28); name opens FaturaSheet; paid shows "Pago". Group "Faturas de cartão". Edit a card: footer link (§7). |
| Only one kind of bill | No group headers: the list as today, title and subtitle as above. |
| Day chosen (≥ 1024) | Rows of that day only; groups without a match hidden; matching groups forced open; counts stay month-level. |
| Large amounts | `R$ 99.999,99` in a row: as today (SOL-152 W8). In a summary, "falta R$ 99.999,99" is its own nowrap fragment; the line wraps, never clips, no horizontal scroll at 375. |
| Long names | Row name truncates with `title` as today; group names are short and fixed. |
| Paying / undoing | Buttons disabled while the mutation runs (as today). |
| Edit tapped before bills load | The name button is `disabled` until `useBills()` has data. |
| Excluir | Sheet closes; the row leaves Mês at once; toast "Conta fixa excluída" + Desfazer (5 s); title and group counts follow the visible rows. Desfazer brings it back, no request sent. Error: row returns, toast "Não foi possível excluir a conta fixa." |
| Excluir the last bill | The card disappears; Desfazer brings it back. |
| Offline / server error | Existing toasts: "Não foi possível marcar como paga.", "Não foi possível desfazer o pagamento.", the one above. |
| Loading / month error | Page-level, unchanged (HeroSkeleton, PageError). |

## 7. Out of scope

- "Editar cartão" inside FaturaSheet: follow-up card if the owner asks; cards keep the footer path (same 2 taps).
- Removing a card from Mês: an archived card's faturas still owe (D28), so its row would stay; Contas fixas handles it as today.
- Remembering collapsed groups across reloads.
