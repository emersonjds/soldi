# SOL-179: text polish at 375 (usability audit SOL-146, Top 15 item 15)

## What changed

- **Names wrap to two lines** (`line-clamp-2 break-words`) instead of truncating with an ellipsis: conta names (Contas a pagar, Contas fixas list and Próximo Vencimento, Lançamentos bill rows), lançamento titles (note or category path) in Lançamentos, Fatura sheet rows and the Por categoria entries, category names (Para Onde Vai legend, Top 5, group rows, subcategory rows, spending glance), cofrinho names in the cofrinho picker. Amounts stay on one line (`Money`: `whitespace-nowrap tabular-nums`).
- **No automatic hyphenation:** `hyphens-auto` removed from the Termômetro strip label ("Confortável") and the category chip label ("Alimentação"); words break only at spaces, `break-words` / `wrap-break-word` only for a string longer than its box.
- **One title "Lançar"** for the add-entry sheet at every width and from every entry point (top bar, floating button, Mês cards, Para Onde Vai, cofrinhos, planilha). Editing keeps "Editar lançamento" / "Editar Lançamento Recorrente". The subtitle stays (no other copy change).

## Left truncated on purpose

- Secondary one-line captions: the Contas fixas category label, the Fatura row caption, the cofrinho movement caption and the card name chip in a Lançamentos caption (it already wraps to its own line first). They are metadata under a name that now wraps; two lines each would double the row height.
- The Meu ano month-note pill (`max-w-[50%] truncate rounded-full`): a fixed chip.
- Ajustes account value (`truncate` with `title`): an e-mail is one unbroken string; breaking it mid-word reads worse than the ellipsis with the full value in `title`.
- Static empty-state illustrations (`shared/ui/illustrations.tsx`): fixed sample text.
- "Restante da fatura de <mês>" in the Fatura sheet and "Diário previsto" in Lançamentos: fixed copy that fits, not a user name.

## Acceptance

- Unit: name elements carry `line-clamp-2 break-words`; the strip and chip labels carry no `hyphens-auto`; the add sheet is the dialog "Lançar" from each entry point.
- e2e (`web/e2e/mes.spec.ts`): a 60-character conta name and a 60-character note are in the DOM in full, wrap (taller than one line) at 375, and `expectNoClipped` passes at 375, 1024, 1280 and 1440.
