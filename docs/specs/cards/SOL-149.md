# SOL-149 — Salvar on a recurring Conta set to Sempre

Owner report 2026-11-22: adding a Gás bill dated 30/11 with Recorrente on, Salvar Lançamento did nothing.

Cause: Recorrente defaults Quantas vezes to Sempre. Under D36 an open-ended Saída is a conta fixa, so the sheet refused the save without saying so; only the "Criar como Conta Fixa" link below the fold worked. The date played no part.

Fix:
- On Conta + Recorrente + Sempre, Salvar does what "Criar como Conta Fixa" does: it opens Nova conta prefilled from the entry, and saving it creates the entry and the conta fixa ("Conta fixa criada").
- Where the host offers no conta fixa sheet (editing a card entry from the fatura), Salvar shows "Uma conta sem fim é uma conta fixa. Escolha quantas vezes." instead of doing nothing.
- A count (2, 3, 6, 12, Outro) still saves a bounded series, as before.
