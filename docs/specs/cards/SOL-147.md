# SOL-147 — Categorias simples

Owner pick 2026-11-14: audit card 2, items #2, #3, #4, #13 and complaints O1, O3 (`docs/research/2026-11-14-usability-audit.md`).
Goal: on Ajustes › Categorias a first-time user sees their groups at once, adds a subcategory in one tap from the group, and every create or edit opens the same short sheet at every width.
Rules: never more taps than today; nothing the owner uses goes without saying so (§6); plain pt-BR; **Lançar's category step stays exactly as today** (its chips, Ver todas and "Nova categoria" entry are untouched).

## 1. Market (benchmark R9, `docs/research/2026-11-14-market-benchmark.md` §3)

Mobills (Gerenciar › Categorias: Despesas/Receitas tabs, "+" beside the parent), Organizze web ("+ subcategoria" under each parent), YNAB ("+" on the group header). Common: tabs by kind, parents with children indented, "+" on the parent row, tap a row to edit, delete inside edit, no stats on the screen.
Soldi keeps three tabs, not two: the kind drives the thermometer and Lançar already asks Entrada · Conta · Diário, so the words match.

## 3. One sheet (`web/src/entities/category/category-sheet.tsx`)

## 5. States and acceptance criteria

- **Loading**: skeleton rows under the tabs; "Nova categoria" visible and disabled (`aria-disabled`), no layout jump when the list arrives.
- **Error**: "Não foi possível carregar as categorias." + "Tentar de novo".
- **Empty tab**: icon + `Nenhuma categoria de {Diário|Conta|Entrada} ainda.` + button "Criar categoria" → sheet with Tipo = tab.
- **Search, no match**: "Nenhuma categoria encontrada."
- **Overflow**: 40-char names wrap to 2 lines at 375, no horizontal scroll; 30 groups scroll the page only.
- **Offline**: last loaded list stays; save shows the failure message, values kept.
- **Disabled**: Criar while saving or palette full; Excluir absent on Economia; cofrinho with balance → toast "Resgate tudo antes de excluir." (unchanged).

Acceptance (a tester checks at 375×812, 1024×900, 1440×900, light theme):
1. No stat cards, no month switcher, no description line; tabs are visible without scrolling at 375.
2. Each group row has a "+" of 44×44 named "Nova subcategoria em {grupo}" ("Novo cofrinho em Economia"); it opens the sheet titled "Nova subcategoria" with "Dentro de {grupo}" and Nome focused.
3. "Nova categoria", "+", row tap and empty-state button open the same sheet/dialog at all three widths; no form is docked beside the list at any width.
4. Default create (group or "+") needs no scroll at 375×812; "Criar" stays visible at 375×476 (keyboard open) with Nome focused.
5. Saúde (Conta, sub Farmácia Diário) shows in Diário with Farmácia only and no kind label; "+" there creates a Diário sub.
6. Row tap → "Editar categoria" → Excluir → row disappears, toast with "Desfazer" restores it.
7. Duplicate name shows `Já existe "Mercado" em Diário.` under Nome and keeps the sheet open.
8. All targets ≥ 44 px, inputs 16 px; focus ring visible on rows, "+", tabs, swatches; Tab order = visual order; focus returns to the opener after close.
9. Screen reader: list "Categorias de Diário", each group a list item with its name, subs "Subcategorias de {grupo}", row buttons "Editar {nome}", errors announced, toasts polite.
10. Lançar: chips, Ver todas, Nova categoria entry and tap count unchanged (SOL-145 tests stay green).
11. No copy contains "Categoria Pai", "agrupador", "Tipo de Fluxo", "Cor de Destaque", "Ícone Representativo", "Configuração".

## 7. Panel votes (product · ux · finance · architect)

1. Description line: none — ux/architect yes, product wants "Toque num grupo para editar…"; trade-off: one less line vs. first-time hint; revisit if testers miss "+".
2. Three tabs, not Gastos/Receitas: all yes; trade-off: one more tab vs. a mental model that matches Lançar and the thermometer.
3. Drop month totals: ux/architect/product yes, finance yes if Para onde vai has them (it does); trade-off: no amounts here vs. a settings screen that is settings.
4. Drop kebab: all yes; trade-off: Excluir moves one screen deeper, same 2 taps.
5. Keep search: product/ux yes, architect neutral; trade-off: one row of height vs. finding one of ~40 categories.
6. Mixed group not muted: ux/product yes, finance yes; trade-off: the group's own kind is hidden in that tab vs. a row that looks disabled.
7. "+" locks the group: all yes; trade-off: changing the group means another "+" vs. a 12-row list in every sub sheet.
8. Shared sheet improves for Lançar too: product/ux yes, architect yes (one form); trade-off: Lançar's sheet changes look, not steps.
