# SOL-173 One occurrence of a conta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** one month of a conta fixa or parcelada gets its own amount or is skipped, Projetado and every reader follow at once, and the existing `PayBillSheet` offers it from Contas a pagar, Lista and Planilha.

**Architecture:**

- Server: table `bill_months` (migration 0033). `months::domain` takes a `BillMonths` map (keyed like `Faturas`) in `amount_in`, `owed`, `unpaid`, `auto_paid`, `month_view`, `forecast`. `PUT`/`DELETE /api/bills/{id}/months/{month}` in the bills slice. `pay` and `insert_auto_payments` book the override.
- Web: one mutation `useSetBillMonth` (PUT or DELETE); `PayBillSheet` gains Salvar valor / Pular / Voltar a cobrar / Editar conta; rows read `adjusted` / `skipped`.

**Tech Stack:** axum 0.8 + sqlx + utoipa; Next.js 16 static export, TanStack Query, openapi-fetch, sonner, Vitest, Playwright.

**Spec:** `docs/specs/cards/SOL-173.md` (UX brief §1–9, Technical spec §1–7), D56 in `docs/specs/decisions.md`. Worktree `/Users/emerson/Documents/workspace/open-source/soldi-173`, branch `feat/SOL-173-one-occurrence`.

    month      date NOT NULL CHECK (extract(day FROM month) = 1),
    amount     numeric(12, 2) CHECK (amount > 0),

);

/// D56: a month keeps its own amount, a skip, or both; neither is `DELETE`.
pub fn check_month(input: SetBillMonth) -> Result<SetBillMonth, AppError> {
    match input.amount {
        None if !input.skipped => Err(AppError::invalid("amount", "is required unless the month is skipped")),
        Some(amount) if amount <= Decimal::ZERO => Err(AppError::invalid("amount", "must be greater than zero")),
        Some(amount) => Ok(SetBillMonth { amount: Some(check_money("amount", amount)?), ..input }),
        None => Ok(input),
    }
}

/// D56: a conta fixa or parcelada owes `month` from `active_since`'s month, inside its run (D35).
pub fn check_occurrence(bill: &MonthBill, month: NaiveDate) -> Result<(), AppError> {
    if bill.closing_day.is_some() {
        return Err(AppError::rule("card-month", "A card's fatura has no amount of its own per month."));
    }
    if month < first_of(bill.active_since) || !runs_in(bill, month) {
        return Err(AppError::rule("month-outside-bill", "This bill owes nothing that month."));
    }
    Ok(())
}

/// D56: `month`'s own amount or skip; never a card, outside the run or on a paid month.
pub async fn set_month(pool: &PgPool, user: &CurrentUser, id: Uuid, month: &str, input: SetBillMonth) -> Result<(), AppError> {
    let month = parse_month(month)?;
    let input = domain::check_month(input)?;
    let mut tx = pool.begin().await?;
    // D55's order is settings → entries → bill rows; a catch-up or a Pagar sees this month before or after.
    transactions::repo::lock_entries(&mut tx, user.id).await?;
    let bills = months::repo::bills(&mut tx, user.id).await?;
    let bill = bills.iter().find(|bill| bill.id == id).ok_or(AppError::NotFound)?;
    domain::check_occurrence(bill, month)?;
    if repo::paid_in(&mut tx, user.id, id, &[month]).await? {
        return Err(AppError::conflict("bill-already-paid", "This bill is already paid this month."));
    }
    repo::set_month(&mut tx, user.id, id, month, &input).await?;
    tx.commit().await?;
    Ok(())
}

    repo::find(&mut tx, user.id, id).await?.ok_or(AppError::NotFound)?;
    repo::delete_month(&mut tx, user.id, id, month).await?;
    tx.commit().await?;
    Ok(())
}

```ts
export const useSetBillMonth = () => {
  const client = useQueryClient();
  return useMutation({
    mutationFn: async ({ billId, month, amount, skipped }: MonthChange) => {
      const params = { path: { id: billId, month } };
      if (amount === null && !skipped)
        return okOrThrow(await api.DELETE("/api/bills/{id}/months/{month}", { params }));
      return okOrThrow(await api.PUT("/api/bills/{id}/months/{month}", { params, body: { amount, skipped } }));
    },
    onMutate: (change) =>
      patchRow(client, change, (row) => ({
        amount: change.amount ?? change.normal ?? row.amount,
        adjusted: change.amount !== null,
        skipped: change.skipped,
        ...(change.skipped && { lands_on: null, overdue: false }),
      })),
    onError: (_error, _change, rollback) => rollback?.(),
    onSettled: () => refresh(client),
  });
};
```
