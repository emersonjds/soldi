> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Invoke the `tdd` skill before the first line of code; report red and green per task.

**Goal:** Lançar picks any group or subcategory from one sheet, creates a missing one inline, and creates a credit card without ever asking for a category.

**Architecture:** Server: a `categories.is_card_group` flag (migration 0029) and `CreateBill.category_id` optional on a card, resolved to the card group inside `bills::service::create` (D43). Web: `CategoryPicker` (entities/category) replaces `CategoryChips` + `CategorySelect` in Lançar and the purchase simulator; `CardSheet` (entities/bill) creates a card from Lançar's Diário card field and from the card group's `+`.

**Tech Stack:** axum 0.8 + sqlx + utoipa; Next.js 16 static export, TanStack Query, openapi-fetch, shadcn, Vitest, Playwright.

**Spec:** `docs/specs/cards/SOL-140.md` (brief, Fintech review, "Technical design"), D43. Worktree `/Users/emerson/Documents/workspace/open-source/soldi-140`, branch `feat/SOL-140-categories-in-lancar`.

```rust
// categories/service.rs
/// D43: the account's active card group; with none, `Cartão` is created, or an active `bill`
/// named `Cartão` is adopted.
pub async fn card_group(conn: &mut PgConnection, user: &CurrentUser) -> Result<Uuid, AppError> {
    if let Some(id) = repo::find_card_group(conn, user.id).await? {
        return Ok(id);
    }
    let taken = repo::top_colors(conn, user.id, &[CategoryKind::Bill], None).await?;
    let color = domain::pick_color(None, &taken)?;
    Ok(repo::insert_card_group(conn, user.id, &color).await?)
}
```

```rust
// categories/repo.rs
pub async fn find_card_group(conn: &mut PgConnection, user_id: Uuid) -> Result<Option<Uuid>, sqlx::Error> {
    sqlx::query_scalar!(
        "SELECT id FROM categories WHERE user_id = $1 AND is_card_group AND archived_at IS NULL",
        user_id
    )
    .fetch_optional(&mut *conn)
    .await
}

pub async fn insert_card_group(conn: &mut PgConnection, user_id: Uuid, color: &str) -> Result<Uuid, sqlx::Error> {
    sqlx::query_scalar!(
        "INSERT INTO categories (user_id, name, kind, icon, color, is_card_group)
         VALUES ($1, $2, 'bill', 'credit-card', $3, true)
         ON CONFLICT (user_id, kind, (lower(name))) WHERE archived_at IS NULL
         DO UPDATE SET is_card_group = true, updated_at = now()
         RETURNING id",
        user_id,
        super::domain::CARD_GROUP,
        color
    )
    .fetch_one(&mut *conn)
    .await
}
```
