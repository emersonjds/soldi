# SOL-105, SOL-101, SOL-110, SOL-106 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mixed category groups (SOL-105), per-category kind change on top of them (SOL-101), the owner's default category tree (SOL-110), and credit cards whose spends add up to a monthly fatura (SOL-106).

**Architecture:** No new slice. SOL-105 relaxes `categories::domain::check_parent` and widens one color query. SOL-106 makes a card a `recurring_bills` row with `closing_day`; spends carry `transactions.card_id`; `months` folds card rows of its existing `GROUP BY date` query into faturas through one pure function, `bills::domain::fatura_due`.

**Tech Stack:** Rust (axum, sqlx, rust_decimal, chrono), Next.js 16 static export, TanStack Query, openapi-fetch, Vitest, Playwright.

**Spec:** `docs/specs/2026-11-12-categories-and-cards.md` (§ numbers below). **Decisions:** D26, D27, D28, D29.

## Global Constraints

- Money is `rust_decimal::Decimal` / `NUMERIC(12,2)` / string in JSON. Never a float, in Rust or TS.
- Every query filters by `user_id` from the session; every new test proves another user's data is invisible.
- `domain.rs` pure, `repo.rs` sqlx, `service.rs` use cases taking `&CurrentUser`, `handler.rs` JSON. No trait with one implementation.
- Running balance comes from `months::repo::day_sums`, one `GROUP BY date` query. No new query per day, per card or per bill.
- After any SQL change: `scripts/sqlx-prepare.sh`; after any DTO change: `UPDATE_OPENAPI=1 SQLX_OFFLINE=true cargo test -p soldi-server --test openapi`, then `pnpm gen:api` in `web/`.
- Web: FSD imports only downward; 16 px form text, 44 px targets, 375 px first, light only; pt-BR copy verbatim from the spec.
- TDD per slice: the slice's tests written together, one red run, the code, one green run; report red and green.
- Gate per card before merge: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `scripts/sqlx-prepare.sh --check`, `pnpm typecheck`, `pnpm lint`, `pnpm test:coverage`, `pnpm build`.
- One opus agent per task below, ~25 tool calls. Agents commit on green, never merge or push.

```rust
/// D26: colors of the user's active top-levels that show in any of `kinds` (own kind or an
/// active subcategory's), but `except`.
pub async fn top_colors(
    conn: &mut PgConnection,
    user_id: Uuid,
    kinds: &[CategoryKind],
    except: Option<Uuid>,
) -> Result<Vec<String>, sqlx::Error> {
    let kinds: Vec<&str> = kinds.iter().map(|kind| kind.as_str()).collect();
    sqlx::query_scalar!(
        "SELECT c.color FROM categories c
         WHERE c.user_id = $1 AND c.parent_id IS NULL AND c.archived_at IS NULL
           AND c.id IS DISTINCT FROM $3
           AND (c.kind = ANY($2) OR EXISTS (
                SELECT 1 FROM categories s
                WHERE s.user_id = $1 AND s.parent_id = c.id AND s.archived_at IS NULL
                  AND s.kind = ANY($2)))",
        user_id,
        &kinds as &[&str],
        except
    )
    .fetch_all(&mut *conn)
    .await
}

/// The category's own kind and its active subcategories' kinds.
pub async fn group_kinds(
    conn: &mut PgConnection,
    user_id: Uuid,
    id: Uuid,
) -> Result<Vec<CategoryKind>, sqlx::Error> {
    sqlx::query_scalar!(
        r#"SELECT DISTINCT kind AS "kind!: CategoryKind" FROM categories
           WHERE user_id = $1 AND (id = $2 OR (parent_id = $2 AND archived_at IS NULL))"#,
        user_id,
        id
    )
    .fetch_all(&mut *conn)
    .await
}
```

```rust
/// D26: a group that shows in a kind where its color is taken moves to the lowest token free
/// in every kind it shows in, or keeps its color when none is.
pub async fn fit_group_color(
    conn: &mut PgConnection,
    user: &CurrentUser,
    parent_id: Uuid,
) -> Result<(), AppError> {
    let parent = repo::find_active_shared(conn, user.id, parent_id).await?.ok_or(AppError::NotFound)?;
    let kinds = repo::group_kinds(conn, user.id, parent_id).await?;
    let taken = repo::top_colors(conn, user.id, &kinds, Some(parent_id)).await?;
    if !taken.contains(&parent.color) {
        return Ok(());
    }
    if let Ok(color) = domain::pick_color(None, &taken) {
        repo::set_color(conn, user.id, parent_id, &color).await?;
        repo::recolor_children(conn, user.id, parent_id, &color).await?;
    }
    Ok(())
}
```

```rust
async fn change_kind(conn: &mut PgConnection, user: &CurrentUser, category: &Category, kind: CategoryKind)
    -> Result<(), AppError> {
    let parent = match category.parent_id {
        Some(id) => repo::find_active_shared(conn, user.id, id).await?,
        None => None,
    };
    domain::check_kind_change(category, parent.as_ref(), kind)?;
    if repo::name_taken(conn, user.id, category.id, kind).await? {
        return Err(domain::duplicate_name(kind, &category.name));
    }
    if kind == CategoryKind::Daily && repo::has_active_bills(conn, user.id, category.id).await? {
        return Err(domain::category_has_bills());
    }
    repo::change_kind(conn, user.id, category.id, kind).await?;
    match category.parent_id {
        Some(parent_id) => fit_group_color(conn, user, parent_id).await,
        None => {
            let kinds = repo::group_kinds(conn, user.id, category.id).await?;
            let taken = repo::top_colors(conn, user.id, &kinds, Some(category.id)).await?;
            if taken.contains(&category.color) {
                let color = domain::pick_color(None, &taken)?;
                repo::set_color(conn, user.id, category.id, &color).await?;
                repo::recolor_children(conn, user.id, category.id, &color).await?;
            }
            Ok(())
        }
    }
}
```

```rust
/// D28: the due date of the fatura a spend dated `on` joins. A spend before the month's
/// clamped closing day closes this month, on or after it the next; the fatura is due in the
/// closing month when `due_day` is after `closing_day`, else in the month after.
pub fn fatura_due(on: NaiveDate, closing_day: i16, due_day: i16) -> NaiveDate {
    let next = |month: NaiveDate| month.checked_add_months(Months::new(1)).unwrap_or(month);
    let month = first_of(on);
    let closes = if on < due_date(month, closing_day) { month } else { next(month) };
    due_date(if due_day > closing_day { closes } else { next(closes) }, due_day)
}
```

```rust
/// D28: each card's fatura, keyed by (card id, first day of its due month).
pub fn faturas(bills: &[MonthBill], sums: &[DaySum]) -> HashMap<(Uuid, NaiveDate), Decimal> {
    let mut found = HashMap::new();
    for sum in sums {
        let card = sum.card_id.and_then(|id| bills.iter().find(|bill| bill.id == id));
        if let Some((card, closing_day)) = card.and_then(|card| Some((card, card.closing_day?))) {

            *found.entry((card.id, first_of(due))).or_default() += sum.amount;
        }
    }
    found
}
```

```ts
const pad = (value: number) => String(value).padStart(2, "0");
const lastDay = (year: number, month: number) => new Date(Date.UTC(year, month, 0)).getUTCDate();
const clamped = (year: number, month: number, day: number) =>
  `${year}-${pad(month)}-${pad(Math.min(day, lastDay(year, month)))}`;
const next = ([year, month]: [number, number]): [number, number] => (month === 12 ? [year + 1, 1] : [year, month + 1]);

export const faturaDue = (date: string, closingDay: number, dueDay: number) => {
  const [year, month] = date.split("-").map(Number);
  const own: [number, number] = [year, month];
  const closes = date < clamped(year, month, closingDay) ? own : next(own);
  const [dueYear, dueMonth] = dueDay > closingDay ? closes : next(closes);

};
```
