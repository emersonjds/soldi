Steps use checkbox (`- [ ]`) syntax for tracking. Invoke the `tdd` skill before the first line of code; report red and green per task.

**Goal:** a monthly Conta series turns into one conta fixa whose past and current months keep their entries as payments, and a conta fixa can be marked as having a variable amount.

**Architecture:**

- Server: `recurring_bills.variable` (migration 0030) flows through `Bill`, `CreateBill`, `UpdateBill`, `MonthBill` and `BillOfMonth`.
- `bills::service::create` with a `transaction_id` that is a series member checks the series, takes its lock, inserts the bill and runs `transactions::repo::link_series`. That deletes the members after this month and links the rest as payments, all in one DB transaction (D44).
- Web: `BillForm` gains a "Valor varia todo mês" switch and accepts a parcelado prefill. Contas a pagar and Contas fixas mark a variable bill. `TransactionSheet` offers Criar como Conta Fixa on a monthly series member and hides it where the server refuses.

**Tech Stack:** axum 0.8 + sqlx + utoipa; Next.js 16 static export, TanStack Query, openapi-fetch, shadcn, Vitest, Playwright.

**Spec:** `docs/specs/cards/SOL-152.md` (decisions §2, challenges §3, accepted movements §4, acceptance §6), D44. Worktree `/Users/emerson/Documents/workspace/open-source/soldi-152`, branch `feat/SOL-152-contas-mensais`.

```rust
/// D44: a member of a monthly `bill` series off any card brings its series into a conta fixa.
pub fn check_series_convertible(entry: &Transaction) -> Result<(), AppError> {
    let monthly = entry
        .series
        .as_ref()
        .is_some_and(|series| matches!(series.every, RepeatEvery::Month));
    let loose = entry.recurring_bill_id.is_none() && entry.cofrinho_id.is_none() && entry.card_id.is_none();
    if entry.kind != CategoryKind::Bill || !loose || !monthly {
        return Err(cannot_become_bill());
    }
    Ok(())
}
```

```rust
/// D44: what keeps a series from becoming one conta fixa.
pub struct SeriesBlockers {
    /// A member is not a plain `bill` entry.
    pub mixed: bool,
    /// Two members dated through `through` share a month.
    pub shared_month: bool,
}

pub async fn series_blockers(
    conn: &mut PgConnection,
    user_id: Uuid,
    series_id: Uuid,
    through: NaiveDate,
) -> Result<SeriesBlockers, sqlx::Error> {
    let row = sqlx::query!(
        r#"SELECT COALESCE(bool_or(kind <> 'bill' OR card_id IS NOT NULL OR cofrinho_id IS NOT NULL
                                   OR recurring_bill_id IS NOT NULL), false) AS "mixed!",
                  count(*) FILTER (WHERE date <= $3)
                    > count(DISTINCT date_trunc('month', date)) FILTER (WHERE date <= $3)
                    AS "shared_month!"
           FROM transactions WHERE user_id = $1 AND series_id = $2"#,
        user_id,
        series_id,
        through
    )
    .fetch_one(&mut *conn)
    .await?;
    Ok(SeriesBlockers { mixed: row.mixed, shared_month: row.shared_month })
}

/// D44: deletes the series' members after `through`; the rest become `bill_id`'s payments, out of
/// any series, each keeping its date, amount, note and category.
pub async fn link_series(
    conn: &mut PgConnection,
    user_id: Uuid,
    series_id: Uuid,
    bill_id: Uuid,
    through: NaiveDate,
) -> Result<(), sqlx::Error> {
    sqlx::query!(
        "DELETE FROM transactions WHERE user_id = $1 AND series_id = $2 AND date > $3",
        user_id,
        series_id,
        through
    )
    .execute(&mut *conn)
    .await?;
    sqlx::query!(
        "UPDATE transactions
         SET recurring_bill_id = $3, series_id = NULL, series_every = NULL, series_open = false,
             series_offset = 0, updated_at = now()
         WHERE user_id = $1 AND series_id = $2",
        user_id,
        series_id,
        bill_id
    )
    .execute(&mut *conn)
    .await?;
    Ok(())
}
```

```rust
            transactions::repo::lock_series(&mut tx, member.id).await?;
            let through = month_end(first_of(crate::today_sao_paulo()));
            let blockers =
                transactions::repo::series_blockers(&mut tx, user.id, member.id, through).await?;
            if blockers.mixed {
                return Err(transactions::domain::cannot_become_bill());
            }
            if blockers.shared_month {
                return Err(transactions::domain::series_shared_month());
            }
            series = Some((member.id, through));
        }
    }
}
// … category resolution and repo::insert unchanged …
match (transaction_id, series) {
    (Some(_), Some((series_id, through))) => {
        transactions::repo::link_series(&mut tx, user.id, series_id, bill.id, through)
            .await
            .map_err(transactions::service::paid_once)?;
    }
    (Some(id), None) => {
        if !transactions::repo::link_bill(&mut tx, user.id, id, bill.id, bill.category_id).await? {
            return Err(transactions::domain::cannot_become_bill());
        }
    }
    (None, _) => {}
}
tx.commit().await?;
```

```ts
const SERIES_HINT =
  "Os lançamentos desta série até este mês viram pagamentos desta conta. Os dos próximos meses saem da lista: a conta passa a prever cada mês.";

/** D20's series day: the last member's, or the larger of the two when it sits clamped on its month's last day. */
const seriesDay = (lastDate: string, date: string) => {
  const day = Number(lastDate.slice(8));
  return day === lastDay(lastDate.slice(0, 7)) ? Math.max(day, Number(date.slice(8))) : day;
};

/** D44: a series still running after this month keeps its end as a parcelado bill. */
const prefillOf = (source: Source): BillPrefill => {
  const { note, category, amount, date } = source;
  const prefill = { name: (note ?? category.name).slice(0, 100), amount, due_day: Number(date.slice(8)), category_id: category.id };
  const series = "series" in source ? source.series : undefined;
  if (!series) return prefill;
  const month = series.last_date.slice(0, 7);
  const runsOn = !series.open_ended && month > todayISO().slice(0, 7);
  return {
    ...prefill,
    due_day: seriesDay(series.last_date, date),
    ...(runsOn && { installments: series.total, last_month: `${month}-01` }),
  };
};
```
