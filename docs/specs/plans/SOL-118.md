# SOL-118 Implementation Plan: Fixo sem fim, parcelado com início e fim

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Invoke the `tdd` skill before the first line of each task; report red and green.

**Goal:** Contas fixas end at a month (Parar, parcelado Fies) without touching past months; Lançar gets open-ended Fixo series that grow as months are read, and parcelas that start at k.

**Architecture:** Bills gain `last_month` + `installments`, and `active` becomes derived. One gate in `months::domain::owed` serves month view, D17 carry and forecast. Series gain `series_open` + `series_offset`. `transactions::service::extend_open_series` reuses D19 growth before month view, forecast and ledger read rows. No new route, no job, no new query per day.

**Tech Stack:** Rust (axum 0.8, sqlx 0.9, rust_decimal, chrono), Next.js 16 static export, TanStack Query, openapi-fetch, Vitest, Playwright.

**Spec:** `docs/specs/cards/SOL-118.md` › Technical design (edges, copy, acceptance). **Decisions:** D35, D36 (and D14, D16, D17, D19, D28, D30, D32, D33).

## Global Constraints

- Money is `rust_decimal::Decimal` / `NUMERIC(12,2)` / string in JSON. Never a float.
- Every query filters by `user_id`; every new integration test proves another user's rows are untouched.
- `domain.rs` pure, `repo.rs` sqlx, `service.rs` takes `&CurrentUser`, `handler.rs` JSON. No trait with one implementation.
- The running balance stays `months::repo::day_sums`, one `GROUP BY` query. Growth adds 1 indexed query per read, plus writes only when a series is behind.
- Past months never change on Parar or at the last parcela (owner, 2026-11-12).
- After SQL changes: `scripts/sqlx-prepare.sh`. After DTO changes: `UPDATE_OPENAPI=1 SQLX_OFFLINE=true cargo test -p soldi-server --test openapi`.
- Web: FSD imports only downward, 16 px form text, 44 px targets, 375 px first, light only, pt-BR copy verbatim from the spec.
- Commits: Conventional Commits in English, no trailer, files added by name, one per green task.
- Tests use the real São Paulo today (`soldi_server::today_sao_paulo()`): any date that depends on today is computed from it, never hard-coded.

// months/domain.rs
/// Months since year 0; two of them subtract to their distance.
pub fn month_index(date: NaiveDate) -> i32 {
    date.year() * 12 + i32::try_from(date.month0()).unwrap_or(0)
}

// bills/domain.rs
/// D35: the parcela `month` holds when parcela `installments` falls in `last_month`.
pub fn installment_of(month: NaiveDate, last_month: NaiveDate, installments: i16) -> Option<i16> {
    let k = i32::from(installments) - (month_index(last_month) - month_index(month));
    i16::try_from(k).ok().filter(|k| (1..=installments).contains(k))
}

/// D35: Parar ends after this month, or after a month already paid ahead.
pub fn stop_month(today: NaiveDate, last_paid: Option<NaiveDate>) -> NaiveDate {
    let this = first_of(today);
    last_paid.map_or(this, |paid| this.max(first_of(paid)))
}

pub fn bill_ended() -> AppError {
    AppError::rule("bill-ended", "This bill ended before that month.")
}

// transactions/domain.rs
/// D36: open series are written through the forecast horizon, or `viewed` when later, never past
/// 60 months from today nor 2100.
pub fn open_until(today: NaiveDate, viewed: NaiveDate) -> NaiveDate {
    use crate::months::domain::horizon_end;
    let cap = horizon_end(today.checked_add_months(Months::new(48)).unwrap_or(today));
    let until = horizon_end(today).max(viewed).min(cap);
    NaiveDate::from_ymd_opt(2100, 12, 31).map_or(until, |end| until.min(end))
}

/// D36: the members an open series still needs after `end` (its last members, last first) to reach `until`.
pub fn open_dates(every: RepeatEvery, end: &[NaiveDate], until: NaiveDate) -> Result<Vec<NaiveDate>, AppError> {
    use crate::months::domain::month_index;
    let Some(&last) = end.first() else {
        return Ok(Vec::new());
    };
    let steps = match every {
        RepeatEvery::Month => month_index(until) - month_index(last),
        RepeatEvery::Week => i32::try_from((until - last).num_days() / 7).unwrap_or(0),
        RepeatEvery::Year => until.year() - last.year(),
    };
    let dates = growth_dates(every, end, u32::try_from(steps).unwrap_or(0))?;
    Ok(dates.into_iter().filter(|date| *date <= until).collect())
}

// repo.rs
/// D36: the last member of each of the user's open series that ends before `until`.
pub async fn open_series_behind(conn: &mut PgConnection, user_id: Uuid, until: NaiveDate) -> Result<Vec<Uuid>, sqlx::Error> {
    sqlx::query_scalar!(
        r#"SELECT id AS "id!" FROM (
               SELECT DISTINCT ON (series_id) id, date FROM transactions
               WHERE user_id = $1 AND series_open ORDER BY series_id, date DESC, id DESC) last
           WHERE last.date < $2"#,
        user_id,
        until
    )
    .fetch_all(&mut *conn)
    .await
}

// service.rs
/// D36: grows the user's open series through `until`, copying each one's last member under its lock.
pub async fn extend_open_series(pool: &PgPool, user: &CurrentUser, until: NaiveDate) -> Result<(), AppError> {
    let behind = repo::open_series_behind(&mut *pool.acquire().await?, user.id, until).await?;
    for id in behind {
        let mut tx = pool.begin().await?;
        let Some(series) = repo::find(&mut tx, user.id, id).await?.and_then(|last| last.series) else {
            continue;
        };
        repo::lock_series(&mut tx, series.id).await?;
        let Some(last) = repo::find(&mut tx, user.id, id).await?.filter(|last| last.series.as_ref().is_some_and(|s| s.open_ended)) else {
            continue;
        };
        let end = repo::series_end(&mut tx, user.id, series.id).await?;
        let dates = domain::open_dates(series.every, &end, until)?;
        if !dates.is_empty() {
            let amounts = vec![last.amount; dates.len()];
            repo::insert_copies(&mut tx, user.id, &domain::copy_of(&last), series.id, series.every, &dates, &amounts).await?;
        }
        tx.commit().await?;
    }
    Ok(())
}
